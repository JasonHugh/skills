# booklet-print — 小册子正反打印排版 Skill

把一本 PDF 书变成"家用打印机手动双面打印 → 装订 → 可翻阅"的成品。

## 何时使用

用户想打印一本书/绘本并装订成册时。典型触发：
- "这本书做成打印版" / "做成正反打印的"
- "做成小册子" / "打印出来装订好"
- 提供 PDF 并说明家用打印机要手动翻面

## 两种装订方案（先让用户选）

| 方案 | 每张 A4 纸 | 成品 | 跨页效果 | 适合 |
|------|-----------|------|---------|------|
| **骑马钉对折**（默认推荐） | 正反各 2 页，共 4 页/张 | A5 小书，对折套叠中缝订 | 翻开的跨页连续 | 最省纸、装订简单 |
| **平装左订** | 正反各 2 页并排 | A4 半页大小，左边装订 | 每张纸就是一整跨 | 跨页要完整、不拆散 |

页数必须是 **4 的倍数**（骑马钉）或 **4 的倍数**（平装每纸 4 页）。不是就补空白页。

## ⚠️ 必做：先询问是否删无关页省纸

**生成前必须主动问用户**：要不要删掉书里的无关页面来省纸。这是固定环节，不要跳过——很多绘本前几页是扉页/版权页/广告页，删掉能少用整张纸，用户通常乐意。

### 步骤
1. 渲染**原书每一页**的缩略图，拼成一张带页码的总览图（方法见工作流 §2）。
2. 自己先看一遍，标出候选的"无关页"，再用提问让用户确认。**绝不擅自删**，一定要用户点头。
3. 用 `AskUserQuestion` 问，把候选页码列清楚：

> 这本书共 34 页，我看到以下页面可能是无关内容，删掉可以省纸：
> - 第 2、3、4 页：扉页 / 版权页 / 广告页
> - 第 33 页：空白页
> 封面（第 1 页）和封底（第 34 页）会保留。要删掉这些页吗？

### 哪些算"无关页"（可建议删）
- 扉页、版权页、出版信息页
- 纯广告页、二维码推广页、"关注公众号"页
- 空白页、纯色页
- 目录页（用户不想要时）

### 哪些**不能删**
- 封面（原书第 1 页）和封底（最后一页）——用户明确要求保留
- 任何有故事正文/插画的页面

### 省纸账要算给用户看
删页后告诉用户"从 X 张纸省到 Y 张纸"（页数向上凑到 4 的倍数决定纸张数）。例如 34 页→30 页→补 2 白=32 页=8 张纸，比原来的 9 张省 1 张。

### 删页的实现
用户确认页码后，通过 `--drop 2,3,4,33` 传给脚本。**按原书页码**删，不是成品页码。删完再补白到 4 的倍数，补白放正文之后、封底之前（见下文跨页规律）。

## ⚠️ 最核心的坑：左右跨页规律（用户最容易不满意的点）

### 原书页面规律
绘本常见排版：**奇数页 = 文字，偶数页 = 插画**，连续的奇偶对 `[5|6] [7|8] …` 才构成一幅完整跨页（左右画面衔接）。

### 骑马钉的物理特性（务必理解）
骑马钉装订后，读者**翻开的跨页 = [逻辑页2k | 逻辑页2k+1]**。
例如成品第一跨是逻辑 2|3，第二跨是逻辑 4|5，以此类推。

而一张纸的正反面在 PDF 里是**跳号**的：
```
纸 s 正面: [N-2s | 2s+1]     例 N=32, s=0 → [32|1]（封底|封面）
纸 s 反面: [2s+2 | N-2s-1]   例 s=0 → [2|31]
```
这是正常的——PDF 里看着"跳"，但**装订后翻阅顺序是正确的**。不要试图让 PDF 每页看着连续，那会毁掉装订后的顺序。

### 正确构造逻辑序列（关键）
要让成品翻开的跨页是原书的 `[5|6] [7|8] …`，必须把原书页按连续顺序放进逻辑位：
```
logical = [封面] + [原书连续正文页...] + [空白补齐] + [封底]
```
这样成品跨页 `[logical[2]|logical[3]]`、`[logical[4]|logical[5]]` 就正好是原书连续奇偶对。

**错误做法（踩过）**：把空白插在逻辑第 2 位 → 成品第一跨变成 `[空白|原5]`、第二跨 `[原6|原7]`，奇偶错位，用户会说"左页变到右页"。

### 空白页放哪
- 需要补白时，把空白放在**正文之后、封底之前**（逻辑序列末尾连续几个 None）
- 这样成品最后几跨是空白，封面/封底仍在最外张
- 不要插在封面后（逻辑第 2 位）——会打乱奇偶

### 删页的处理
用户说"删掉原书第 X,Y,Z 页"时：直接从 `logical` 的原书页列表里跳过这些页号，再补白到 4 的倍数。**按原书页码删，不是按成品页码删。**

## ⚠️ 第二个大坑：页面尺寸不一致导致左右图大小不同

### 现象
用户反馈"有的页面左右两张图大小不一样"。

### 根因
同一 PDF 里混有不同尺寸的页面（如多数 21×23cm，少数 28×31cm）。宽高比不同（大页更方、小页更瘦长），用**统一缩放比**等比缩放后，大页仍比小页大一圈。

### 错误尝试
统一 `scale` → 无效，宽高比不同导致物理尺寸仍不一致。

### 正确做法：固定目标框 + 非等比拉伸
1. 找出全书最小可用缩放：`base_scale = min(AVAIL_W/w, AVAIL_H/h)` 对所有页面取最小
2. 目标框固定为 `TARGET_W = 参考宽 * base_scale`，`TARGET_H = 参考高 * base_scale`
3. 每一页分别用 `sx = TARGET_W/该页宽`、`sy = TARGET_H/该页高` 拉伸到**精确填满同一目标框**
4. `Transformation().scale(sx=..., sy=...)` 分别给 x/y 不同比例

代价：尺寸不同的页有极轻微形变（宽高比 1.095→1.096 级别，肉眼无感）。换来同一张纸上左右两图物理尺寸严格一致。

## 完整工作流

### 1. 检查 PDF
```python
from pypdf import PdfReader
r = PdfReader(src)
n = len(r.pages)
sizes = set((round(float(p.mediabox.width)),round(float(p.mediabox.height))) for p in r.pages)
# 数页数、尺寸分布、mod 4
```
- 页数不是 4 的倍数 → 记下需要补几张空白
- 尺寸不止一种 → 必须用"固定目标框"策略

### 2. 渲染缩略图总览 + 询问删页省纸（必做）
把原书每页渲染成缩略图拼总览，用视觉模型看：
- 哪些页是封面/封底/扉页/版权页/广告页/空白页 → **据此询问用户是否删无关页省纸**（见上方"必做"章节）
- 哪些奇偶对是连续跨页（画面在中间接缝处衔接、背景色一致）
- 据此确定跨页规律是奇左偶右还是偶左奇右

用户说"左右不对"时尤其要仔细看跨页衔接。用户主动指定删页时按指定页码删，否则先询问再删。

渲染方法（macOS 无 poppler/fitz 时）：pypdf 拆单页 PDF → `sips -s format png -Z 300` → Pillow 拼图。拼图示例：
```python
from PIL import Image, ImageDraw
import glob, os
thumbs = sorted(glob.glob(f"{tmpdir}/*.png"))
COLS, W, PAD, LABEL_H = 6, 300, 10, 26
cell_w = W + PAD; cell_h = int(W*1.45) + LABEL_H + PAD
ROWS = (len(thumbs)+COLS-1)//COLS
canvas = Image.new("RGB",(COLS*cell_w+PAD, ROWS*cell_h+PAD),"white")
draw = ImageDraw.Draw(canvas)
for idx,t in enumerate(thumbs):
    img = Image.open(t).convert("RGB")
    img = img.resize((W, int(img.height*W/img.width)))
    x,y = PAD+(idx%COLS)*cell_w, PAD+(idx//COLS)*cell_h
    canvas.paste(img,(x,y))
    p = int(os.path.basename(t).split("_")[1].split(".")[0])
    draw.text((x+6, y+img.height+4), f"原书第{p}页", fill="black")
canvas.save("总览.png")
```
再用视觉模型读总览图，逐页判断内容类型。

### 3. 构造逻辑序列
```python
DROP = {2,3,4,33}  # 用户要删的原书页码，空集合表示不删
keep = [p for p in range(1, n+1) if p not in DROP]
logical = [keep[0]] + keep[1:-1] + [None]*pad + [keep[-1]]  # 空白插在封底前
# 断言 len(logical) % 4 == 0
```

### 4. 生成 PDF
用 `scripts/build_booklet.py`（参数化脚本，见下）。核心 API：
- `PageObject.create_blank_page(width=A4_W, height=A4_H)` 建 A4 横向纸（841.89 × 595.276 pt）
- `base.merge_transformed_page(src, op)` 合并变换后的源页
- **反面不做镜像**——双面打印翻面由打印机驱动处理，PDF 正反面都正常排版

### 5. 校验
- 成品页数 = 逻辑页数 / 2（每张纸正反 2 面）
- 所有页 mediabox 是 A4 横向
- 打印"成品翻阅跨页"表，确认是连续奇偶对
- 渲染几张纸确认左右图大小一致、内容顺序正确

### 6. 输出与告知
- 输出到用户指定目录（常是 workspace 的 `prints/` 文件夹）
- **必须把下方「教用户打印」的方法一并告诉用户**（或放一份通用打印说明到输出目录）
- 如用户要，上传到资料库

## 🖨️ 教用户打印（生成整合版后必做）

成品是**正反面交替的单个 PDF**（第 1 面正面、第 2 面反面、第 3 面正面…），用最简单的「浏览器打印 + 分两次打」即可，不需要打印机支持自动双面。

### 标准话术（直接告诉用户）

> 打印很简单，用浏览器打两次就行：
> 1. **双击打开** `xxx_打印版.pdf`（默认用浏览器打开），按 `Ctrl/Cmd + P` 调出打印对话框。
> 2. 页面范围选 **奇数页**（1、3、5…），先打这一批。纸张方向选**横向**，缩放选 **100% / 实际大小**，别勾"适合页面"。
> 3. 打完后 **整份纸拿起来，原样翻过来**（正反调面），放回打印机纸盒。
> 4. 再打印 **偶数页**（2、4、6…）。
> 5. 打完就得到正反都印好的纸，每张沿中线对折、套叠、中缝订一下即可。

### 为什么这样可以
浏览器/打印驱动打印多页是**从后往前**出纸的，所以打完奇数页那一叠的顺序刚好反过来——整份翻面后直接放回去打偶数页，正反面就自动对齐了，不用手动重排纸张顺序。

### 关键提醒
- **翻面方式**：整份"拿起来翻过来"即可，不要逐张重排。若打印后发现反面上下颠倒，改成沿另一条轴翻面（横向纸一般翻长边）。
- **先试一张**：批量前先用奇数页打 1 张、翻面打对应偶数页，确认对齐再全打，省纸。
- 若浏览器"页面范围"只接受连续区间，可用「自定义范围」输入 `1,3,5,7,9`（每张纸正面）和 `2,4,6,8,10`（反面）。页数多时用工具的"奇数页/偶数页"选项（Chrome 在"更多设置"里有）。
- 打印质量选"照片/高质量"，绘本以图为主。

### 注意
- 这套方法是针对**整合版**（正反交替单 PDF）。若输出的是老式「正面.pdf + 反面.pdf」两个文件，则分别单面打印即可，方法不同——不要混用。

## 技术要点速查

- **A4 横向**：`A4_W=841.89, A4_H=595.276` pt；半页宽 `HALF_W=420.945`
- **边距（重要）**：`OUTER_MARGIN=8`（纸张四周安全边距，别改小，家用打印机有 3~5mm 不可打印区会裁掉画面）；`CENTER_GAP=4`（每半页靠中缝留白，左右合计中间留白 = `2*CENTER_GAP = 8pt ≈ 2.8mm`）。**外侧和中缝必须分开控制**——若用一个 MARGIN 同时管两者，调小中缝会连外侧一起缩到 1.4mm，打印被裁
- **可用区**：`AVAIL_W = HALF_W - OUTER_MARGIN - CENTER_GAP`，`AVAIL_H = A4_H - 2*OUTER_MARGIN`
- **定位**：左页左边缘贴 `OUTER_MARGIN`，右页左边缘贴 `HALF_W + CENTER_GAP`（不是固定在 `HALF_W/2`），两页都拉伸到同一个 `TARGET_W×TARGET_H` 目标框
- **pypdf 的 `reader.pages` 是只读 `_VirtualList`**，不能 `.append()`。补白通过构造 `logical` 序列时插入 `None` + 自定义 `get_page()` 实现，不要改 reader
- **安装**：`pip3 install pypdf Pillow`（brew 装 poppler 可能因系统 git 太老失败；PyMuPDF/fitz 也可能装不上；macOS 用 `sips` 转图）
- **大文件**：URL 含特殊字符时写入文件用 `curl -K` 读取，不要直接塞命令行

## 脚本用法

```bash
python3 scripts/build_booklet.py \
  --input 书.pdf \
  --output 输出目录/书_打印版.pdf \
  --mode saddle \
  --drop 2,3,4,33 \
  --verify
```

`--mode`: `saddle`（骑马钉）| `flat`（平装左订）
`--drop`: 逗号分隔的原书页码，空则不删（询问用户后决定）
`--target-from`: `first`（默认，用第一页比例定目标框）| `smallest`（全书最小缩放）
`--verify`: 打印成品翻阅跨页表和尺寸校验

工作流顺序：检查 PDF → **渲染总览并询问删页省纸** → 构造逻辑序列 → 生成 → 校验 → 输出。
